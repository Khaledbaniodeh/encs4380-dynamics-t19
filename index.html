ENCS4380 / INTERFACING TECHNIQUES

Built to make
sensor dynamics visible.

A course project by Team T19 at Birzeit University. Explore the lecture’s first- and second-order models through interactive experiments.

These are mathematical simulations. A real sensor follows a model only when that model’s assumptions apply.

Do I need to install anything?

No. Open the website in your browser. The experiments load Python and plotting libraries over the internet; no account or app is needed.

Can I open it on my phone?

Use the same website link in your phone’s browser. Inside Module 1, “Open on phone” also provides a QR code and a copyable link.

Where should I start?

Start with Module 1 to explore how a sensor responds to a sudden change. Continue to frequency response in Module 2, then damping and state space in Module 3.

What is “Guess the sensor”?

The planned fourth module asks you to estimate hidden sensor parameters from an unfamiliar response curve, then compare your guess with the true model. It is not available in this version.
