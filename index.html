About the toolkit

Learn the response, not just the equation.

Dynamics Lab is a course project for ENCS4380 Interfacing Techniques at Birzeit University, created by Team T19. It turns the lecture’s sensor models into experiments you can change and inspect.

These are mathematical simulations. Real sensors fit these models only when the models’ assumptions apply.

What does “first order” mean?

A first-order model describes a response with one time constant, τ. In Module 1, the sensor approaches a new reading gradually; a larger τ means it takes longer.

What do input, output and error mean?

The input is the quantity being measured. The output is the sensor’s reported reading. During a change, a gap can remain between the reading and its ideal value. Each experiment explains how that gap is measured.

Can I use it on my phone?

Open this same website in your phone’s browser. No app or login is needed. Inside Module 1, Open on phone provides a QR code and a copyable link. Internet access is needed to load the calculation and plotting libraries.
