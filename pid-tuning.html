Why can the second-order plant overshoot and settle below 1?

Its damping ratio determines whether the step response overshoots or rings. With the fixed input u = 1, the unregulated final output approaches the hidden plant gain K, which can differ from the target r = 1. The tuned PID adds feedback to correct that error.

What the code does: RK4 advances three plant states, detects successive maxima, and uses bisection between decaying and growing oscillations to estimate Ku. Pu is measured from the distance between peaks. This is the classic closed-loop ultimate-gain form of Ziegler–Nichols; it provides a starting controller, not a guarantee that the original P4 performance specifications will pass. This experiment uses an ideal (unlimited) actuator, independently of the main challenge's ±10 actuator limit.

What's happening behind the scenes?

The same control concepts used in P1 and the random-plant challenge style from Homework 1 Module 4.

e(t) = r(t) − y(t)
u(t) = clip[Kp·e(t) + Ki·∫e(t)dt − Kd·filtered(dy/dt)]
First order: τ·dy/dt + y = K·u
Second order: d²y/dt² + 2ζωn·dy/dt + ωn²·y = Kωn²·u

The plant's continuous dynamics are advanced with a handwritten 4th-order Runge–Kutta (RK4) solver, using held control commands. The derivative acts on output rather than the setpoint, and conditional integration prevents integral windup against actuator limits. The hidden plant and a private reference PID generate feasible challenges.

How do we judge the result?

Overshoot: maximum output above the setpoint. Settling: first entry to the ±2% band after which the full remaining response stays in-band, with at least 0.5 s of evidence. Steady error: final absolute tracking error under 1% AND no significant final-window movement. These numerical conventions are stated here because the assignment does not prescribe exact tolerances or scoring.
