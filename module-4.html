How to estimate the parameters

            

              
1. Gain (K): Read the final steady-state value of the step response. For a unit step, that value estimates K.

              
2. Time constant (τ): Find 63.2% of that final value on the vertical axis. The time when the response first reaches that level estimates τ.

              
Alternative: Plot ln|K − y(t)| against time. Its slope is approximately −1/τ.

            

            

              
1. Frequency: ω is displayed above the plot in rad/s. The gray line is the unit input sine (amplitude A = 1).

              
2. Find τ: Compare the peaks of the input and output to measure the phase lag |φ| in radians. Then τ ≈ tan(|φ|) / ω.

              
3. Find K: Estimate the sensor's output amplitude B. The amplitude ratio is B/A = K / √(1 + (ωτ)²), so K ≈ (B/A) √(1 + (ωτ)²).

              
Use several cycles for a better estimate. The plot shows the steady-state sine response.

            

            

              
1. Overshoot: Estimate the first peak yₚ and final value y∞. Calculate Mₚ = (yₚ − y∞) / y∞.

              
2. Damping ratio (ζ): Use ζ = −ln(Mₚ) / √(π² + [ln(Mₚ)]²).

              
3. Natural frequency (ωn): Read the time to the first peak, Tₚ. Then ωn = π / (Tₚ √(1 − ζ²)).

              
Use the overall trend rather than a single noisy dot when reading the peak.
