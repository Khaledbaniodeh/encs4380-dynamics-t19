1. The physical system

We reuse the mass-spring-damper model from Homework 1, Module 3:

m x'' + b x' + k x = u

State vector: X = [x, v]ᵀ
Feedback:     u = -K₁x - K₂v
Closed loop:  X' = (A - BK)X

This is a regulation experiment: the controller drives displacement and velocity toward zero. It is not nonzero-setpoint tracking.
