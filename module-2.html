Why does the combined waveform change shape?

1. Add the input waves: x(t) = sin(ω₁t) + A₂ sin(ω₂t). The blue curve is their sum.

2. Filter each frequency: a linear sensor responds to each wave separately, so yss(t) = M₁ sin(ω₁t + φ₁) + A₂M₂ sin(ω₂t + φ₂).

3. Compare input and output: faster changes are attenuated more and phase-shifted further. The combined green output can look smoother or different.

Example (τ = 0.2 s): at ω₁ = 2 rad/s, M₁ ≈ 0.928; at ω₂ = 12 rad/s, M₂ ≈ 0.385. Increase τ, or set A₂ = 0 to go back to a single sine.

How is τmax calculated?

Require M ≥ 1 − e, with e = allowed error / 100. Since M = 1 / √(1 + (ωτ)²), solving for τ gives τmax = √(1/(1−e)² − 1)/(2πfmax). The phase calculation uses τmax, not your current τ.

Why does M change when ω changes?

The amplitude ratio is M = 1 / √(1 + (ωτ)²). In this exercise we keep τ fixed and increase ω, the input's angular frequency.

Step 1 — Think about the formula. Increasing ω makes the product ωτ larger. Its square becomes larger too, so the denominator √(1 + (ωτ)²) increases. When you divide 1 by a larger number, the result is smaller. Therefore M decreases.

Step 2 — Think about the sensor. With a slow-changing input, the sensor has more time to follow each rise and fall, so the output amplitude is close to the ideal value. At higher frequencies, the input changes direction more quickly than the sensor can follow, so the measured swings become smaller.

Step 3 — Separate amplitude from phase. The input sine still has amplitude 1. It is the sensor output that gets attenuated. At the same time, the output phase becomes more negative, meaning the output peaks lag behind the input peaks.

Worked example (τ = 0.2 s): at ω = 2 rad/s, M ≈ 0.928, but at ω = 10 rad/s, M ≈ 0.447. The amplitude ratio drops as the frequency rises even though the sensor and input amplitude stay the same.

M(2, 0.2) = 1 / √(1 + 0.4²) ≈ 0.928
M(10, 0.2) = 1 / √(1 + 2²) ≈ 0.447
